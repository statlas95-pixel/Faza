## Последняя проверенная версия

- **Тег `v0.2`** — все этапы цикла 0.2 завершены и проверены (16.11.2026).
- Запуск: `npm install`, затем `npm start` → http://localhost:8787 (Windows: `start.bat`). Нужен Node.js ≥ 22.13.

## Проверено живыми запросами

- **Crossref REST API** — да: curl и через сервер платформы (`/api/search/external`), включая реальный ответ 429 и повтор.
- **Anthropic API** — только достижимость и отказ авторизации (401 без ключа). Успешный ответ модели живьём **не получен**: ключа в среде нет.
- **OpenAI-совместимый провайдер** — только на локальной заглушке и в тестах.
- **OpenAlex** — не проверялся (нужен ключ); код есть, включается переменной `OPENALEX_API_KEY`.
- **SMTP** — не проверялся; без него письма сброса пишутся в `data/outbox`.
- **Docker-образ и публичное размещение** — не проверялись.

## Первый реальный запрос к ИИ-наставнику

1. Скопировать `.env.example` в `.env`, задать `ANTHROPIC_API_KEY=...`.
2. `npm start`; в консоли должна появиться строка «ИИ-наставник: claude-opus-5-5, claude-sonnet-5-5, claude-haiku-5-5».
3. Войти в аккаунт, открыть любую тему, кнопка «Наставник» → «Объяснить» → «Спросить».
4. Если модель отклонена провайдером — интерфейс покажет причину; список моделей правится в `ANTHROPIC_MODELS`.

## Ошибки, найденные и исправленные в этом цикле

- Прототип: у трёх источников не было DOI — подтверждены через Crossref и добавлены.
- Прототип: `scripts/check-content.mjs` не различал `transfer`-ссылку и `transfer`-блок вопросов.
- Новое: тайм-аут поиска 8 с был мал для длинных запросов к Crossref — увеличен до 15 с, добавлена пауза между обращениями.
- Новое: вывод «не отличим от шума» в занятии DoE сравнивался с «двумя сигмами» — заменено на t-интервал по числу повторов.
- Новое: таблица плана опытов обрезалась по горизонтали; тип источника в каталоге показывался кодом (`paper`).
- За прокси Node не использует `HTTPS_PROXY` без `NODE_USE_ENV_PROXY=1` — описано в `docs/DEPLOY.md`.

## Известные ограничения

- Реальных фотографий нет; визуальный реверс-инжиниринг сайтов не проводился (нет доступа из среды).
- Источники сверены по каталогам и записям Crossref, полные тексты не открывались.
- Подтверждения адреса почты при регистрации нет.
- Занятия-расчёты (кроме расследований) передают наставнику только вводную и связанные темы, без состояния ученика.
