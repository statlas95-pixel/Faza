# Фаза — образовательная платформа для косметических химиков и технологов

Русскоязычная база знаний и интерактивные занятия по технологии производства и разработке косметики.
Версия 0.3: десять тем и девять занятий, входная диагностика, профиль навыков и объяснимый маршрут, карта знаний, личные аккаунты, поиск внешних источников (Crossref), ИИ-наставник с выбором модели. Состояние и следующий шаг — в `HANDOFF.md`, план — в `docs/ROADMAP.md`.

## Запуск на Windows

Нужен [Node.js LTS](https://nodejs.org) версии 22.13 или новее.

**Полная версия (аккаунты, поиск источников, ИИ-наставник):** двойной щелчок по `start.bat`, либо в терминале:

```bash
npm install
```

```bash
npm start
```

Откройте http://localhost:8787. Данные лежат в папке `data/` рядом с проектом.

**Без установки:** откройте `dist\index.html` двойным щелчком. Темы и занятия работают полностью, прогресс хранится в браузере; аккаунт, внешний поиск и наставник в этом режиме недоступны и честно помечены.

**Настройки** (ключи ИИ, почта, адрес сервера): скопируйте `.env.example` в `.env`. Размещение онлайн — `docs/DEPLOY.md`.

## Команды

| Команда | Что делает |
|---|---|
| `npm start` | Сборка и запуск сервера на порту 8787 |
| `npm run dev` | Режим разработки: сервер + интерфейс с автообновлением (http://localhost:5173) |
| `npm run check` | Проверка контента: ссылки на термины, источники, темы, изображения, согласованность сценариев |
| `npm test` | Тесты расчётных моделей, сервера, авторизации, поиска и слоя ИИ |
| `npm run build` | Проверка типов и сборка для сервера (`dist/`) |
| `npm run build:single` | Всё приложение одним файлом `dist-single/index.html` |
| `npm run candidates` | Источники, которые пользователи предложили редактору |

## Структура

```
content/            ВЕСЬ научный контент — правится без программирования
  topics/*.md       темы (Markdown + шапка с метаданными и проверочными вопросами)
  labs/*.yaml       сценарии занятий
  glossary.yaml     термины
  sources.yaml      реестр источников с пометками о проверке
  media/, media.yaml  изображения и их реестр (автор, источник, лицензия)
  site.yaml         маршруты главной страницы
  about.md          страница «О платформе»
  tech-docs.yaml    каталог первичных технических документов (поиск «по каталогу платформы»)
src/                интерфейс
  models/physics.ts расчётные модели (Стокс, проходы, охлаждение, Гершель — Балкли, солевая кривая, эффекты плана)
  labs/             движки занятий: investigation, stability, scaleup, rheo, salt, doe
  account.ts        вход, синхронизация, импорт локального прогресса
  features/         поиск источников, панель наставника
server/             сервер: auth.ts, db.ts (миграции), search.ts (Crossref/OpenAlex), ai.ts (провайдеры), app.ts (API)
shared/merge.ts     слияние копий прогресса — общий код браузера и сервера
tests/              тесты моделей
scripts/            проверка контента
docs/AUTHORING.md   инструкция автора
```

Без входа прогресс хранится в `localStorage` браузера; после входа — на сервере (SQLite) с локальным кэшем. Платные API нужны только для ИИ-наставника и необязательны.
