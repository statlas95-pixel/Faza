# Работа над «Фазой»

«Фаза» — русскоязычная учебная платформа для косметических химиков и технологов. При работе с Димой объясняй изменения на русском и указывай, как увидеть результат в приложении.

## Где что менять

Перед изменением логики прочитай `docs/ARCHITECTURE.md`: там зафиксированы существующие подходы, постоянные идентификаторы и совместимость прогресса. Результаты последнего аудита — в `HANDOFF.md`.

- Теория и проверочные вопросы находятся в `content/topics/`, сценарии занятий — в `content/labs/`. Словарь и источники находятся в `content/glossary.yaml` и `content/sources.yaml`.
- Связи тем, предпосылок и навыков задают `content/curriculum.yaml`, `content/skills.yaml` и `content/diagnostic.yaml`. При изменении учебного маршрута проверь, что объяснение рекомендации соответствует навыкам ученика.
- Страницы и виджеты находятся в `src/`, общая логика прогресса — в `shared/`, сервер и ИИ-наставник — в `server/`. Учитывай прогресс пользователей, сохранённый предыдущими версиями.
- Для учебных расчётов указывай единицы, допущения и допустимую погрешность. Проверяй числовой ответ независимым пересчётом. Синтетические данные помечай явно.

## Запуск и проверка

Используй Node.js 24, как в Dockerfile. Из корня проекта выполни `npm ci`. Команда `npm run dev` запускает интерфейс и сервер для разработки. Команда `npm start` собирает и запускает приложение на http://localhost:8787.

Перед передачей изменений запусти `npm run check` для учебного контента, `npm test` для тестов и `npm run build` для проверки типов и сборки. Различай проверки, выполненные сейчас, и результаты из старого журнала. Для этих трёх команд ключ Cerebras не требуется.

## Откуда продолжать

Восстановленная редакция основана на коммите 67b0090. При восстановлении проверены 19 тем, 16 занятий, 223 термина и 74 теста. Это историческая исходная точка; новые результаты фиксируй в `HANDOFF.md`, не выдавай старые прогоны за текущие.

При аудите воспроизведены и исправлены переполнение каталога и карты на мобильном экране и скрытие выбранного термина фильтрами словаря. Корректная прямая ссылка без фильтров уже имела подсветку. При изменении этих разделов проверяй фильтры, прямые ссылки и фактическую прокрутку к записи.

Репозиторий проекта — statlas95-pixel/Faza. Render автоматически публикует main. Разработку веди в рабочей ветке. Для ручного обновления Deploy-F по запросу Димы подготовь ZIP с Dockerfile и package-lock.json в корне. Ключи, рабочая база и node_modules в архив исходников не входят.
