# Контрольная точка учебной карты

Ветка `feat/planned-curriculum`, база `4085a23`. Добавлены все 20 тем, ранее обозначенных в карте как план, и 20 связанных двуязычных практикумов. Карта, поиск по темам, навыки и маршруты используют общий набор идентификаторов. Пример для проверки от лица ученика — открыть `/#/topics/ionic-strength`, ответить на вопрос, затем перейти к занятию и решить задачу с разбавлением.

Локально прошли проверка содержания, 127 тестов и обе сборки. Для каждой новой задачи независимый тест проверяет начальный расчёт и задачу на перенос. В браузере пройдены вопросы и практикумы на русском при ширине 390 px и на английском при ширине 1360 px. Предметная рецензия материалов специалистом предстоит. Сохраняются восемь предупреждений у прежних библиографических записей без DOI и URL.

На момент сохранения этой точки предстоят проверка GitHub CI и публикация на Render. Результат публикации привязывается к слитому коммиту. Фактический остаток лимита ChatGPT неизвестен, документированный счётчик сессии недоступен.

## Предыдущая контрольная точка аудита

PR №7 слит в `main`. Рабочий сайт https://faza-1boj.onrender.com публикует коммит `9133b7569bca7ea6125cf63832b88cb2e4320d1b`. Render подтвердил статус `live` для `dep-dc1kpee417fc73bmvqng`. База разработки `44235f3`, контрольная точка аудита `99ac2e4`, итоговая рабочая ветка `feat/audit-bilingual` на `a8d99ec`. Изменения с отчётом о публикации содержат только документацию.

Аудит и исправления описаны в HANDOFF. Английская версия доступна через `/?lang=en#/diagnostic`. В CI успешно завершились 107 тестов, обе сборки, проверка контента, рабочего контейнера и установленных зависимостей. Сохранность старой записи в SQLite проверена при миграции v1 → v2 и повторном открытии.

На публичном сайте проверены 51 маршрут в двух языках при ширинах 320 и 1360 px, 204 просмотра. Ошибок JavaScript, ответов 5xx, битых вставок и горизонтального переполнения в этом прогоне не зафиксировано. Пройдены смена языка в начатой диагностике и продолжение занятия на другом языке. Проверка здоровья и поиск по английскому каталогу ответили HTTP 200. Проверка настоящих аккаунтов и платного провайдера ИИ в этот этап не входила.

Фактический остаток лимита ChatGPT неизвестен, документированный счётчик не предоставлен. Следующий содержательный этап — предметная вычитка технического английского и пилот двуязычного кейса о смачивании порошков. Ближайшее улучшение кода — регулярная браузерная проверка перехода RU ↔ EN с продолжением работы и учёт статуса рецензии перевода. Критерии описаны в `docs/DEVELOPMENT_PROPOSALS.md`.
