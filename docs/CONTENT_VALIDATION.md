## Исправления, которые меняют учебный вывод

* В расчёте пристенного сдвига показатель 0,5 давал ошибочный множитель 1,5. При степенном законе (3n+1)/(4n) даёт 1,25.
* Для сорбата отношение долей недиссоциированной формы при двух pH ранее переносилось на величину антимикробной защиты. Пересчитана масса кислоты при дозировке соли. В теме, диагностике и разборе партии результат испытания ограничен условиями, для которых он получен.
* Уточнены концентрационная база солевых добавок, состав знаменателя в задаче про цитрат и различие между локальной буферной ёмкостью и дозой для конечного изменения pH.
* Для неполного факторного плана честный ответ о недостаточности данных получает зачёт. При оценке 95 %-го интервала проверяется вхождение нуля. Для вывода о взаимодействии требуются четыре сочетания при одном уровне третьего фактора. Четверть оценки занятия зависит от четырёх выводов ученика. Остальные три четверти распределены между планом с повторами, выбором уровня и прогнозом. Новая оценка применяется при отправке решения.
* В английских условиях восстановлены обороты в минуту, Па·с, мПа·с, мН/м, моль/л, кг/м³ и другие единицы. В исходных переводах встречались минуты вместо оборотов в минуту и MPa·s вместо mPa·s. Проверка перевода чувствительна к регистру префикса вязкости.

## Как проверялась практика

30 занятий используют движок рабочих листов. Для числовых ключей контрольные формулы заданы отдельно от конфигурации занятий. В них используются исходные концентрации, массы, расходы и теплофизические параметры из условий. Для 20 последних практикумов проверяются оба ключа каждой задачи. Для прежних занятий добавлен независимый пересчёт переноса, включая отдельный ключ пристенного сдвига в кабинете реолога. В синтетических моделях проверены предельные случаи, отношения величин и воспроизводимые сценарии. В постановках о реальной стабильности, безопасности и допуске числовая модель не заменяет измерения на конкретном продукте.

В каждом из трёх расследований проверены документы, доступность оснований из разбора и достижимость поддержанных данными вердиктов при бюджете запросов. Такая проверка выявляет логические тупики. Одно совпадение с журналом в рамках учебной рубрики не устанавливает производственную причину в реальной партии.

## Границы валидации

Для части учебников и стандартов доступна библиографическая карточка, аннотация или фрагмент. Постраничная сверка всех утверждений со всеми первоисточниками остаётся открытой. Приоритет для независимого рецензента — выводы о микробиологической защите, применимость нормативов на выбранном рынке, оценка причины отклонения по неполным записям и перенос режимов на производственное оборудование. Вычитка длинных английских пояснений специалистом также предстоит. Числа в учебных партиях синтетические. Валидация не является валидацией производственной методики.
