# Размещение и конфигурация

## Что запускается

Один процесс Node.js (`server/index.ts`): отдаёт интерфейс из `dist/`, API `/api/*`, хранит данные в SQLite-файле.
Отдельный сервер базы данных не нужен.

| Что | Где | Комментарий |
|---|---|---|
| База | `<FAZA_DATA_DIR>/faza.db` | аккаунты, сессии, прогресс, попытки, кэш поиска. Делайте резервную копию файла |
| Секрет сессий | `FAZA_AUTH_SECRET` или `<данные>/auth-secret` | создаётся при первом запуске; при смене секрета все сессии сбрасываются |
| Письма сброса пароля | SMTP (`SMTP_URL`) или `<данные>/outbox/*.txt` | без SMTP письмо читает тот, кто имеет доступ к серверу |
| Ключи ИИ | `ANTHROPIC_API_KEY`, `OPENAI_API_KEY` | только в окружении сервера |

Все переменные — в `.env.example`.

## Локально (Windows)

`start.bat` или `npm install`, затем `npm start` → http://localhost:8787. Требуется Node.js 22.13+ (LTS 22 или 24).
В корпоративной сети с прокси добавьте в окружение `NODE_USE_ENV_PROXY=1` и `HTTPS_PROXY=...`
(при собственном корневом сертификате — `NODE_EXTRA_CA_CERTS=путь\к\ca.pem`), иначе внешний поиск и ИИ не выйдут в сеть.

Доступ коллег в локальной сети: запустите с `FAZA_BASE_URL=http://<имя-или-IP-компьютера>:8787` и откройте порт 8787 в брандмауэре Windows.
По обычному http cookie работает; для доступа из интернета нужен https.

## Онлайн

Подойдёт любой хостинг, который запускает контейнер или Node-процесс и даёт **постоянный диск**:

```bash
docker build -t faza .
```

```bash
docker run -d -p 8787:8787 -v faza-data:/data -e FAZA_BASE_URL=https://faza.example.org --env-file .env faza
```

Обязательно:

1. `FAZA_BASE_URL` — публичный https-адрес. От него зависят cookie (флаг Secure), проверка источника запросов и ссылки в письмах сброса пароля (адрес возврата: `<FAZA_BASE_URL>/#/account?reset=…`).
2. Постоянный том для `/data`. На платформах без диска данные пропадут при перезапуске.
3. `SMTP_URL` и `SMTP_FROM` — иначе пользователи не смогут сами восстановить пароль.
4. https обеспечивает хостинг или обратный прокси (Caddy, nginx). Если перед сервером стоит прокси, пробросьте заголовок `Origin` без изменений.

Не проверено в этом цикле: сборка Docker-образа и работа на конкретном хостинге (в среде разработки нет Docker и внешнего размещения).

## Обновление версии

Остановить процесс → сделать копию `faza.db` → обновить код → `npm install` → `npm start`.
Миграции собственных таблиц (`server/db.ts`) и таблиц авторизации применяются при старте автоматически и повторно не выполняются.
Прогресс, сохранённый версией 0.1 в браузере, читается версией 0.2 без преобразований и предлагается к импорту в аккаунт после входа.
